# Codegen MCP Server - Test Examples

Test scripts demonstrating Codegen MCP Server functionality.

## Quick Test

**File:** `quick_test.py`

Simple validation script (runtime: ~30-60 seconds)

```bash
export CODEGEN_API_KEY="your-api-key"
export CODEGEN_ORG_ID="323"
python examples/quick_test.py
```

## Configuration

Both scripts use environment variables:

```bash
export CODEGEN_API_KEY="sk-92083737-4e5b-4a48-a2a1-f870a3a096a6"
export CODEGEN_ORG_ID="323"
```

See `../CODEGEN_MCP_GUIDE.md` for complete documentation.
